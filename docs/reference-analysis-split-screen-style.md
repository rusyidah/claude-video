## Style DNA
- **Pacing:** layout alternates full-frame and split about every 5-10 s; text changes inside a layout more often than the layout itself.
- **Typography:** condensed bold sans for headline/key phrases; monospace small caps for labels; captions as short phrases on solid accent chips (not full sentences).
- **Colour:** near-black base, one acid green accent, white text; accent used only for the emphasised word, active item, borders and glow.
- **Motion:** fade-in from dim, list items append, border highlight moves, cursor clicks; cards tilt in perspective with glow.
- **Framing:** speaker is kept off-centre or in a rounded crop so text has its own half; background blur in full frame.
- **Attention control:** one highlighted element at a time; layout switch resets attention.
- **Audio:** unverified.
